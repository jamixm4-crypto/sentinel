Кроссплатформенный защитный сканер с открытым исходным кодом для выявления программ скрытого наблюдения: кейлоггеров, коммерческого сталкерского ПО (Stalkerware), скрытых утилит удалённого доступа (RAT), программ учёта рабочего времени, корпоративных EDR/MDM-агентов и сторожевых процессов (process watchers/anti-kill).

По умолчанию работает **строго на чтение** (read-only), без фоновых служб, без отправки телеметрии в сеть и с нулевым локальным следом в режиме повышенной безопасности.

## Быстрый старт

### 1. Рекомендуемый способ: Проверенные бинарные релизы

Для инструментов безопасности прямая передача скрипта в командный интерпретатор (`curl | bash` или `irm | iex`) несёт риски. Рекомендуется скачивать проверенные бинарные файлы с контрольной суммой:

1. Скачайте архив для вашей ОС со страницы [GitHub Releases](https://github.com/jamixm4-crypto/sentinel/releases/latest).
2. Сверьте контрольную сумму SHA-256 с файлом `SHA256SUMS`:
   ```powershell
   # Windows (PowerShell)
   Get-FileHash -Path sentinel-windows-x86_64.zip -Algorithm SHA256
   ```
   ```bash
   # Linux / macOS
   sha256sum -c SHA256SUMS
   ```
3. Распакуйте и запустите `sentinel scan`.

### 2. Автоматическая установка (для быстрого развёртывания)

**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/jamixm4-crypto/sentinel/main/install.ps1 | iex
```

**Linux и macOS (Bash):**
```bash
curl -fsSL https://raw.githubusercontent.com/jamixm4-crypto/sentinel/main/install.sh | bash
```

## Запуск аудита

```bash
# Базовый аудит системы на русском языке:
sentinel scan --lang ru

# Режим личной безопасности (вывод только в консоль, без файлов отчёта на диске):
sentinel scan --personal-safety-mode

# Форензик-режим (сканирование смонтированного образа диска или директории):
sentinel scan --scan-path /mnt/extracted_disk

# Экспорт для SIEM (NDJSON в stdout):
sentinel scan --format ndjson
```

- **Детектор маскировки под системные файлы Windows (MITRE T1036.005)**:
  Автоматически выявляет подозрительные процессы с именами `svchost.exe`, `csrss.exe`, `lsass.exe`, `services.exe`, запущенные из каталогов пользователя (`%APPDATA%`, `%TEMP%`, `%USERPROFILE%`).
- **75+ специализированных YAML-правил и 280+ C2-доменов**:
  Анализ активных сетевых сокетов и кэша DNS-клиента (`ipconfig /displaydns`) на предмет связи с командными серверами шпионского ПО (AssoEchap, TinyCheck).
- **Мультимодальная корреляция и регулярные выражения аргументов**:
  Поддержка `cmdline_regex` и `min_matches` предотвращает ложные тревоги от легитимных утилит со схожими именами.
- **Глубокий белый список (Deep Benign Allowlist)**:
  Исключение ложных срабатываний для ПО стриминга (OBS Studio), игровых оверлеев (Discord, Steam), экранных дикторов (NVDA) и средств разработки.

## Режим личной безопасности (`--personal-safety-mode`)

В ситуациях преследования и домашнего насилия внезапное отключение шпионской программы или сохранение отчёта на рабочий стол может насторожить преследователя и спровоцировать физическую агрессию:

- **Нулевой файловый след**: HTML и JSON файлы **не сохраняются** на локальный диск; результаты выводятся только в защищённое окно терминала.
- **Подавление автооткрытия браузера**: браузер не запускается автоматически, не оставляя истории просмотров и кэша.
- **Блокировка изменения системы**: все команды `remove` и `quarantine` **строго заблокированы**.
- **Безопасные контакты**: выводятся ссылки на ресурсы психологической и юридической помощи:
  - [Coalition Against Stalkerware](https://stopstalkerware.org)
  - Международный справочник горячих линий: [Lila.help](https://lila.help)
  - Национальная горячая линия по вопросам домашнего насилия: 1-800-799-SAFE

## Безопасное удаление и карантин

Все операции удаления и карантина работают в режиме **сухого прогона (dry-run) по умолчанию**:
```bash
# Симуляция карантина (показывает, что будет сделано, не трогая файлы):
sentinel quarantine STK-WIN-0042-1

# Реальное выполнение:
sentinel quarantine STK-WIN-0042-1 --execute

# Откат изменений:
sentinel restore <quarantine-id>
```

## Пользовательский белый список (Allowlist)

Если в вашей системе используется специфическая утилита, её можно добавить в локальный список исключений:
```bash
sentinel allow list
sentinel allow add "my_custom_tool.exe"
sentinel allow remove "my_custom_tool.exe"
```

## Честные технические ограничения

1. **Мобильные телефоны (Android / iOS)**:
   Основная масса сталкерского ПО нацелена на смартфоны. Sentinel — сканер для рабочих станций (Windows, Linux, macOS). Он не может проверить внутреннюю память телефона без физического подключения через ADB или выгрузки резервной копии. Для мобильных устройств используйте **MVT (Mobile Verification Toolkit)** от Amnesty International или **TinyCheck**. Sentinel содержит базу C2-доменов мобильного ПО для детекции трафика в локальной сети.
2. **Руткиты уровня ядра (Ring 0)**:
   При компрометации ядра ОС проверки из пользовательского пространства не могут гарантировать 100% достоверность. При подозрении на руткиты рекомендуется проводить аудит со стороннего доверенного носителя.
3. **Аппаратные кейлоггеры**:
   Физические USB-перехватчики и аппаратные жучки в клавиатурах не определяются программными методами; требуется физический осмотр кабелей и разъёмов.
